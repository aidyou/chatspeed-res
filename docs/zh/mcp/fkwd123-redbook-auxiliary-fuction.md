# 小红书辅助MCP

一个专为小红书内容创作者设计的智能辅助工具，提供人设打造、文案生成和违禁词检测三大核心功能。

## 功能特性

### 1. 网红人设打造
- 基于用户兴趣和技能进行精准人设定位分析
- 设计独特形象（昵称、头像、简介）
- 制定内容创作策略和运营方案
- 提供互动策略和流量引爆点

### 2. 爆款文案生成
- 生成5个吸引人的标题（含emoji表情）
- 创作完整正文内容（段落化、表情丰富）
- 提供SEO优化标签
- 运用二极管标题法和爆款关键词

### 3. 违禁词检测
- 三级风险扫描（绝对化用语、虚假宣传、敏感内容）
- 高亮显示违规词汇
- 提供合规替换建议
- 风险等级评估（红/黄/绿）

## 使用流程

1. **选择功能**：用户选择需要使用的功能模块
2. **输入需求**：根据功能要求提供相关信息
3. **智能分析**：系统基于用户输入进行智能分析和生成
4. **输出结果**：提供结构化的结果和建议
