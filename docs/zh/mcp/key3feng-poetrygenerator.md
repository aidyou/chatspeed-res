# 诗词生成助手(MCP&Agent挑战赛)

一款不仅可以根据用户提供的关键词自动生成五言绝句或七言绝句，还可以进一步将这些诗句转化为富有艺术感视频作品的智能创作工具。

一款不仅可以根据用户提供的关键词自动生成五言绝句或七言绝句，还可以进一步将这些诗句转化为富有艺术感视频作品的智能创作工具。
