# ip地址归属地查询

可获取本地公网ip，并且支持任意ip地址归属地查询

### 提供2个免费mcp工具，无需认证，无需付费，开箱即用
#### 1. ip2region 支持任意IP地址归属地查询
#### 2. get_local_ip 获取您本地公网IP

### 非mcp调用，请使用 ifconfig.cc 同样免费
### 使用方法：将以下json添加到配置文件中
json
{
  "mcpServers": {
    "ip2region": {
      "url": "https://mcp.ifconfig.cc"
    }
  }
}
