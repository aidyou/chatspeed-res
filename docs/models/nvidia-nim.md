# NVIDIA NIM

NVIDIA-hosted serverless inference endpoints for development, with access and rate limits varying by account and model.

NVIDIA NIM provides hosted inference endpoints for selected foundation models. Developers can create an API key and connect the OpenAI-compatible endpoint to ChatSpeed, but the model catalog, availability, request limits, and any free access are account- and model-dependent.
