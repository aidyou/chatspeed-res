# Agnes AI

OpenAI-compatible multimodal gateway (text/image/video) with free API credits on sign-up, including free Flash-tier models.

Agnes AI is an AI gateway providing multimodal model APIs (text, image, video generation/understanding) through a single OpenAI-compatible endpoint (https://apihub.agnes-ai.com/v1). New accounts get free API credits, and several models run free, e.g. Agnes 2.0 Flash (agent), Agnes 2.5 Flash, Agnes Image 2.1 Flash. Free public beta terms can change; check the official docs.
