# SenseNova

SenseTime's SenseNova platform with an OpenAI-compatible gateway covering text chat, multimodal understanding, image generation, tool calling and streaming; the Token Plan is currently in a free open…

SenseNova is SenseTime's large-model platform. Its OpenAI-compatible gateway (https://token.sensenova.cn/v1, set as base_url in the OpenAI SDK) provides text chat, multimodal understanding, image generation, tool calling and streaming responses. Quick start: register an account and complete phone verification, create an sk- prefixed API key in the console (API Keys), then point base_url to https://token.sensenova.cn/v1 (cURL / Python both supported). The Token Plan gateway is currently in a free open beta with a credits system (general + Flash-Lite pools, see the free-ai entry); beta status, model list and quota can change — check the platform page before relying on it.
