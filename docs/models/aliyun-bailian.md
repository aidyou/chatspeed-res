# Alibaba Cloud Model Studio

Alibaba Cloud Model Studio (百炼) grants new-user free quota per model (usually 1M tokens, valid 90 days, Beijing region) plus 2,000 free calls/day via Qwen Code OAuth; OpenAI-compatible endpoint.

Alibaba Cloud Model Studio (百炼) is Alibaba Cloud's model service platform (Qwen and partner models). On first activation it automatically grants new-user free quota to each model (usually 1M tokens per model, valid for 90 days, Beijing region only); no real-name verification is needed to use the free quota, and unverified accounts default to hard stop when the quota runs out. Qwen Code OAuth authentication carries an independent free quota of 2,000 calls/day. The OpenAI-compatible endpoint can be connected to ChatSpeed.
